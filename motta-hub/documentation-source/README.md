# Acervo de documentação do Mottainai

Materiais de referência organizados por assunto. O [índice completo](../docs/INDICE-BIBLIOTECA.md) lista os arquivos Markdown e informa a finalidade de cada área.

A documentação geral do ecossistema descreve propostas e estados observados em datas específicas. Para confirmar o comportamento implementado, consulte o repositório do componente. `first-year/` é acervo acadêmico e histórico.

Esta pasta é a fonte organizada do catálogo do Motta-hub. O importador gera `documentation-files/` e `documentations.json` a partir daqui. Preserve nomes e caminhos relativos usados por imagens e links.
